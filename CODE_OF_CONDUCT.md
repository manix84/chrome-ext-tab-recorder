# 🤝 Code of Conduct

## 🌱 Our Pledge

This project should be a practical, respectful place to report issues, suggest improvements, and contribute code.

## ✅ Expected Behaviour

- 💬 Be clear, constructive, and specific.
- 🧠 Assume good intent, especially when discussing bugs or tradeoffs.
- 🧪 Focus feedback on behaviour, evidence, and maintainability.
- 🙌 Make space for people with different levels of experience.

## 🚫 Unacceptable Behaviour

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or sustained disruptive behaviour.
- Publishing private information without permission.
- Spam, trolling, or intentionally derailing project work.

## 🛠️ Enforcement

Project maintainers may remove comments, close issues, block users, or decline contributions that violate this code of conduct.
