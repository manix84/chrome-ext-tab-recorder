# 🛡️ Security Policy

## ✅ Supported Versions

Security fixes are handled for the latest version on the main branch.

## 🔐 Reporting a Vulnerability

Please do **not** open a public issue for security-sensitive reports.

Email Rob Taylor at manix84@gmail.com with:

- 🧩 A description of the issue
- 🔁 Steps to reproduce
- 🖥️ Browser and operating system details
- 📎 Any relevant screenshots, logs, or proof-of-concept notes

## 🎯 Scope

Relevant security concerns include:

- Unexpected recording behaviour
- Incorrect permission use
- Data leaving the browser unexpectedly
- Unsafe handling of downloaded recordings or object URLs

## ⏱️ Response

I will review reports as soon as practical and prioritize issues that affect user privacy, recording control, or data safety.
