# 🧰 Support

## 🐛 Bugs

Open a GitHub issue if the extension does not record, stop, save, or display state correctly.

Useful details:

- 🧭 Chrome version
- 💻 Operating system
- 🔁 Steps to reproduce
- 🎥 Whether the tab has audio or video
- 📁 Whether the download appeared or failed

## 💡 Feature Requests

Feature requests are welcome when they preserve the project goals:

- 🎯 One-click recording
- 🔒 Local-only processing
- 🧹 Minimal UI
- 🙅 No accounts, trackers, analytics, or cloud uploads
