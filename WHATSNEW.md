# ✨ What's New

## 🚀 1.0.0

- 🎥 Added one-click recording for the current Chrome tab.
- 🔊 Captures tab audio alongside video where Chrome supports it.
- 💾 Saves recordings directly to the default downloads folder.
- 🔴 Shows a recording badge while capture is active.
- 🔒 Keeps recording work local to the browser with no accounts, uploads, analytics, or trackers.

## 🧭 Release Notes

- 🧩 Extension versioning is driven by `manifest.json`.
- 📦 `package.json` mirrors the extension version for repository tooling.
- 🪝 The pre-commit hook bumps patch versions by default and keeps both files in sync.
